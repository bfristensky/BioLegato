This directory contains materials related to Issue #6 at https://github.com/bfristensky/BioLegato/issues,

Multiple tabs with panels

This bug was first discovered when creating the blreads menu for ABySS. The comments from this .blmenu file are

#-----------------------
# This menu does not implement the pe parameter of abyss-pe. An attempt was made
# to do that in abyss.blmenu.with-pe. However, when there are two tabs in a tabset,
# both having internal panels, the variables in the first tab fail to get substituted
# on the shell line. This is not explicitly forbidden in the formal PCD definition,
# but may not be fully implemented in BioLegato.
# 
# In summary, BioLegato seems to be able to handle one tab having panels, but not
# more than one may have panels.
#-----------------------

It was rediscovered when trying to implement panels within a tab in the birchadmin --> dbaddprog

A bit of snooping around BioLegato source code shows that parser/CommandThread.java has a Map called widgetInstances, which appears to keep track of all widgets in a menu. Substitution of %% enclosed variables
seems to be donw by shellCommand(replaceArguments(command, widgetInstances), "");
replaceArguments has a method called traverseTree. I am guessing that reverseTree is the culprit behind this bug. Probably it is missing some arguments when there are panels within a tab. Alternatively, is is possible that the widgetInstances doesn't get all the arguments when the parser is scanning for them? The code tells us that by setting PCD.debug to true, we can see the values of %% variables as they are assigned.

It may be relevant that Core ....main/BLMain.java is where the PCD menus are read. This could be important if reading them menus was where the hashtable for %% variables was created. see loadPCD. Turns out that loadPCD is generated by javacc. in pcd.jjt (line 1017):

 * <p>
 *    Each tab can only contain paramter objects,
 *    and each tab MUST contain at least one parameter object.
 * </p>

This is probably where we would have to change the code to somehow allow tabs to have panels.
