FIXED IN BioLegato1.1.4


Running BioLegato (or at least the installer) fails with Java 26.0.1.

Error: Could not find or load main class org.biolegato.sequence.canvas.SequenceCanvas
Caused by: java.lang.NoClassDefFoundError: javax/swing/JApplet

javax.swing.JApplet was present in Java 8 
https://docs.oracle.com/javase/8/docs/api/javax/swing/JApplet.html

It was deprecated in Java 9

https://docs.oracle.com/en/java/javase/17/docs/api/java.desktop/javax/swing/JApplet.html

and scheduled to be removed in Java 26.

Note that Ubuntu 26 has Java 25 as its default JDK.

Search on this error message. Japplet has been removed from recent Java versions. Examples show how to migrate to JFrame.

To find Java src code containing JApplet,
